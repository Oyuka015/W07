    AppFlowy Cloud REST API — лавлах

    Энэ хуудсанд юу баталгаатай, юу биш вэ

    Энд зөвхөн AppFlowy-ийн албан ёсны OpenAPI баримтын индекс хүснэгтэд шууд харагдаж байсан мэдээлэл (класс, метод, HTTP хүсэлт, тайлбар, зам дахь параметрийн нэр, нэвтрэлтийн төрөл) орсон. Параметрийн төрөл, хариуны схем, алдааны код зэргийг би уншиж чадаагүй тул баталгаажаагүй гэж тэмдэглэсэн. Таамаглаж бөглөөгүй. Эдгээрийг OpenAPI YAML/JSON-оос шалгаж бөглөнө үү (доорх "Бөглөх заавар").

    Хамрах хүрээ ба эх сурвалж

    Зүйл Утга
    API AppFlowy Cloud REST API (клиент апп биш, серверийн API)
    Эх сурвалж OpenAPI README
    Хандсан огноо 2026-10-19 (main салбар; тодорхой commit/tag тэмдэглэгдээгүй)
    Base URL https://beta.appflowy.cloud (баримтад "All URIs are relative to" гэж заасан). Self-hosted орчинд өөрийн серверийн URL ашиглана.
    Нэвтрэлт BearerAuth — HTTP Bearer Token (JWT)
    Хувилбар/edition баталгаажаагүй — managed cloud болон self-hosted-д ижил эсэхийг шалгаагүй

    Урьдчилсан нөхцөл: хүчинтэй JWT access token, хандах workspace-ийн гишүүн эрх. Token авах нь баримтын gotrueToken_request / gotrue_token_response моделиудтай холбоотой бололтой боловч схемийг уншаагүй тул баталгаажаагүй.

    Endpoint-ийн хураангуй

    Нэр Метод Зам
    getWorkspaces GET /api/workspace
    getWorkspaceFolder GET /api/workspace/{workspace_id}/folder
    getDatabases GET /api/workspace/{workspace_id}/database
    getDatabaseFields GET /api/workspace/{workspace_id}/database/{database_id}/fields
    getDatabaseRowIds GET /api/workspace/{workspace_id}/database/{database_id}/row
    getDatabaseRowDetails GET /api/workspace/{workspace_id}/database/{database_id}/row/detail
    createDatabaseRow POST /api/workspace/{workspace_id}/database/{database_id}/row
    upsertDatabaseRow PUT /api/workspace/{workspace_id}/database/{database_id}/row

    getWorkspaces

    • Зорилго: Бүх workspace-ийн жагсаалтыг авна ("Retrieves a list of all workspaces").
    • Хувилбар/боломж: баталгаажаагүй
    • Урьдчилсан нөхцөл: Base URL, Authorization: Bearer <ACCESS_TOKEN>
    • HTTP хүсэлт: GET /api/workspace
    Параметр Байрлал Төрөл Заавал эсэх Анхдагч Тайлбар
    — — — — — Замд параметр байхгүй. Query параметр байгаа эсэх: баталгаажаагүй
    • Амжилттай хариу: getWorkspaces_200_response (статус код: баталгаажаагүй)
    • Алдаа: баталгаажаагүй — доорх алдааны хүснэгт-ийг үзнэ үү
    • Жишээ: хүсэлтийн хэлбэр нь дээрх зам ба Bearer нэвтрэлтээс гарсан бөгөөд ажиллуулж баталгаажуулаагүй:
    curl -X GET "https://beta.appflowy.cloud/api/workspace" \
  -H "Authorization: Bearer <ACCESS_TOKEN>"
    • Холбоотой заавар: Хуудас хуваалцах
    • Эх сурвалж: OpenAPI README

    getWorkspaceFolder

    • Зорилго: Workspace-ийн folder эсвэл дэд folder-ыг авна ("Retrieves workspace folder or subfolder").
    • Хувилбар/боломж: баталгаажаагүй
    • Урьдчилсан нөхцөл: Base URL, Authorization: Bearer <ACCESS_TOKEN>

    Параметр Байрлал Төрөл Заавал эсэх Анхдагч Тайлбар
    workspace_id path баталгаажаагүй тийм (замын хэсэг) байхгүй Workspace-ийн танигч

  -H "Authorization: Bearer <ACCESS_TOKEN>"
    • Холбоотой заавар: Анхны төслийн Board
    • Эх сурвалж: OpenAPI README

    Алдааны мэдээлэл

    Алдаа/статус Эх сурвалжид баримтжсан шалтгаан Зөвлөх үйлдэл
    баталгаажаагүй баталгаажаагүй Эхлээд token хүчинтэй эсэх, workspace-д эрхтэй эсэхийг шалгана. Эдгээр нь баримтжаагүй тул таамаглал гэдгийг анхаарна.

    Бөглөх заавар (үлдсэн баталгаажаагүй талбарууд)

    1. OpenAPI YAML/JSON-г нээж, endpoint бүрийн parameters, requestBody, responses хэсгийг хуулна.
    2. Өөрийн workspace дээр (эсвэл туршилтын self-hosted серверт) амжилттай болон алдаатай (token буруу, workspace_id буруу) хүсэлт илгээж, статус код, хариуг тэмдэглэнэ.
    3. Бодит token, workspace id-г баримтад хэзээ ч бүү оруул.
    4. Баталгаажсан мэдээллийг _баталгаажаагүй_ гэсний оронд шивнэ.

    Хэрэв энэ API хүрээ таны даалгаварт тохирохгүй бол

    Багшаасаа AppFlowy Cloud-ийн REST API нь Week 07-ын "public API" шаардлагад тохирох эсэхийг асууна. Зарим эх сурвалж (гуравдагч этгээдийн SDK, MCP төслүүд) нийтийн OpenAPI-д ороогүй endpoint-ууд (жишээ нь page-view) байдаг гэж тэмдэглэсэн. Тэдгээрийг албан ёсны гэж үзэхгүй.
