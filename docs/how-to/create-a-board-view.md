# Даалгавруудад зориулсан Board харагдац үүсгэх

**Хэзээ хэрэглэх вэ:** Даалгавруудаа мэдээллийн санд (жишээ нь Grid) хадгалсан бөгөөд статусаар нь баганаар харахыг хүсэж байна.

## Алхмууд

1. Даалгаврын мэдээллийн сан агуулсан хуудсаа нээнэ.
2. Мэдээллийн сангийн дээд талын харагдацын нэр дээр дарж view цэсийг нээнэ.
3. **+ Add View** дарж **Board**-ыг сонгоно.
4. Бүлэглэх **Single Select** талбарыг сонгоно (анхдагчаар `Status`). Мэдээллийн санд ийм талбар байхгүй бол AppFlowy `Status` талбарыг өөрөө үүсгэнэ.
5. Туршилтаар нэг картыг өөр багана руу чирж зөөнө.

> Хуудас эсвэл мэдээллийн сан шинээр үүсгэх бол sidebar дахь **+** товчоос Board сонгох, эсвэл баримт дотор `/board` гэж бичих аргыг ашиглаж болно.

## Шалгах

Даалгавар бүр Board дээр карт болж харагдаж, зөөсөн карт зөв баганад байна. Мөн Grid харагдац руу шилжихэд тухайн мөрийн `Status` утга шинэчлэгдсэн байна.

## Асуудал гарвал

- **Board сонголт харагдахгүй бол:** та мэдээллийн сан дээр биш энгийн баримт дотор байгаа эсэхээ шалгана. Мөн хувилбарынхаа дэмждэг view төрлүүдийг харна.
- **Карт "No Status" баганад байвал:** картын Status утга хоосон байна. Картыг хүссэн багана руу зөөнө.
- **Багана нуугдсан бол:** хүснэгтийн баруун ирмэг дэх **Hidden groups** хэсгээс **Show** дарна.
