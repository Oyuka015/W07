# Definition of Done — төлөв

✅ = миний бичиж дууссан · ☐ = таны хийх шаардлагатай (би хийж чадахгүй, эсвэл баталгаажуулалт хэрэгтэй)

- ✅ Tutorial бичигдсэн, 8 алхамтай (10-аас ихгүй)
- ✅ Tutorial-д урьдчилсан нөхцөл алхмуудаас өмнө байна, дуусгавар нь шалгах боломжтой үр дүнтэй
- ✅ Гурван тусдаа How-to бичигдсэн
- ✅ How-to бүр "Хэзээ хэрэглэх вэ" нөхцөлөөр эхэлж "Шалгах" хэсгээр төгсдөг
- ✅ API Reference зөвхөн албан ёсны OpenAPI индексэд харагдсан 8 endpoint-ыг агуулсан; үл мэдэгдэх талбарууд "баталгаажаагүй" гэж тэмдэглэгдсэн
- ☐ API Reference-ийн "баталгаажаагүй" талбаруудыг OpenAPI YAML-аас бөглөх
- ☐ Алхмуудыг өөрийн AppFlowy хувилбар дээр бодитоор туршиж, нэршил, дэлгэцийн зургийг шалгах
- ☐ Microcopy-ийн 3 бодит "Before" бичвэр, дэлгэцийн зургийг цуглуулах
- ☐ AppFlowy хувилбар, платформ, deployment горимыг [нүүр хуудсанд](../index.md) бөглөх
- ☐ Сайтыг байршуулах (GitHub Pages гэх мэт) — `mkdocs gh-deploy`
- ☐ Дотоод хайлт Tutorial болон Reference хуудсыг олж байгааг live сайт дээр шалгах (локал build дээр хайлтын индекс үүссэн)
- ☐ `microcopy.diff` болон дэлгэцийн зургуудыг курсын шаардсан байрлалд хадгалах
- ☐ Pull request/тайланд уран зохиолыг иш татаж, өөрчлөлт бүрийг ямар дүрэм үндэслэснийг бичих
- ✅ Reference ба How-to хуудсуудын хоорондын холбоосууд бичигдсэн (build үед шалгана)
