## Туршсан орчин (бөглөж баталгаажуулна) {#test-environment}

Алхмууд хувилбар, платформ, deployment-аас хамаарч өөр байж болно. Нийтлэхээсээ өмнө доорх мөрүүдийг өөрийн туршсан орчноор бөглөнө үү.

| Зүйл | Утга |
|---|---|
| AppFlowy хувилбар | `[жишээ: v0.x.y — Settings/About хэсгээс хуулна]` |
| Платформ | `[Desktop (Windows/macOS/Linux) эсвэл Web]` |
| Deployment | `[AppFlowy Cloud / local-only / self-hosted]` |
| Туршсан огноо | `[YYYY-MM-DD]` |

!!! warning "Хэрэглэх хүрээ"
    Local-only горимд хуваалцах боломжууд хязгаарлагдмал эсвэл байхгүй байж болно. Self-hosted орчинд зарим боломж (жишээ нь Publish, Copy Link to Share) вэб серверийн URL тохируулсны дараа ажиллана.
